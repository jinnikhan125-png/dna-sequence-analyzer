# Sequence Alignment Analysis | Bioinformatics

## Objective

To compare two DNA sequences using ClustalW and observe similarities, differences, and gaps between the sequences.

## Tool Used

- ClustalW 2.1
- Sequence type: DNA

## Input Sequences

### Sequence 1
- Accession: NC_000011.10_c5227071-5225464
- Length: 1608 bp

### Sequence 2
- Accession: AH005432.2
- Length: 1085 bp

## Alignment Results

- Pairwise alignment score: 29.1244
- Multiple alignment score: 2121
- Alignment was successfully generated.
- FASTA alignment file was created by ClustalW.

## Interpretation

The two DNA sequences were successfully aligned using ClustalW. The alignment shows matching regions as well as differences between the sequences.

The `-` symbols represent gaps introduced during alignment. The `N` symbols represent unknown or undetermined nucleotides.

Because the two sequences have different lengths, gaps were introduced to align corresponding regions.

## Conclusion

This analysis demonstrates how ClustalW can be used to compare DNA sequences and identify conserved and variable regions. It provides practical experience with sequence alignment, accession numbers, FASTA format, and interpretation of bioinformatics results.
